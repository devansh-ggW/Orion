Use Orion responsibly.

These terms describe the basic rules for using the current Orion Security Intent Engine website and local analyzer.

Security boundary: Orion is an analysis and repair-assistance tool. It does not guarantee that a project is secure, compliant, or free of vulnerabilities.

1. What Orion does

Orion analyzes project files you provide, identifies patterns that may indicate security problems or hardening opportunities, and generates explanations and repair instructions. Results are signals for investigation, not a substitute for dynamic testing, code review, penetration testing, or professional advice.

2. Your files and authorization

You should only submit code and project files that you own or are authorized to analyze. Do not use Orion to inspect or test someone else's private code without permission.

3. No guarantee

Static analysis can miss issues and can also report patterns that are safe in a particular context. Orion does not promise complete detection, complete remediation, legal compliance, uptime, or a particular security score.

4. Repair instructions

Generated repair briefs are suggestions for a coding agent or developer. You are responsible for reviewing changes, testing them, and deciding whether they are appropriate for your project.

5. Responsible use

You must not use Orion to facilitate unauthorized access, credential theft, malware deployment, disruption of services, or other unlawful activity. You remain responsible for the projects you analyze and the changes you make.

6. Availability and changes

Orion may change, be updated, or become temporarily unavailable. Features and limits may change as the product develops.

7. Support

For product questions or support, email dewifystores@gmail.com.

8. Updates to these terms

We may update these terms as Orion evolves. Continued use of the service after an update means you are using the then-current version.
